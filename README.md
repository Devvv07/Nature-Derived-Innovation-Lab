# Nature-Derived Innovation Lab (NDIL)

An immersive, hybrid STEM skill lab bridging theoretical sciences with nature-derived industrial intelligence. Based in Vadodara, Gujarat, NDIL designs and delivers hands-on biomimicry curriculums, hardware prototypes, and rural outreach solutions for schools, universities, and enterprise partners.

---

## 🌟 Key Features

NDIL operates as a dual-deployment model, pairing a state-of-the-art urban facility with a solar-powered mobile lab:

### 1. Vadodara Innovation Hub (Urban Flagship)
A controlled research and prototyping facility designed to transition biological design principles into functional industrial applications:
- **Observation Atrium**: Live comparative studies of biological systems (plant hydraulics, thermal structures, biomechanics).
- **Analysis Bay**: Advanced workstations running MATLAB, Python, and Finite Element Analysis (FEA) software.
- **Prototyping Workshop**: Complete engineering facility equipped with CNC machining, additive manufacturing (3D printing), and modular robotics.
- **Pitch Arena**: Professional presentation space for student cohorts to pitch designs to industry recruiters and investors.

### 2. Mini-Factory Simulation
An interactive educational environment mirroring modern factory automation, robotic workflows, and industrial packaging systems, all taught through biological emulation.

### 3. BioLab-on-Wheels (Rural Mobile Lab)
A 100% solar-powered, off-grid mobile classroom and laboratory delivering high-caliber STEM training directly to tribal belts, agrarian schools, and rural MSME clusters using regional ecosystems as the primary teaching platform.

## 🎒 Biomimicry Activity Kits (Curriculum)
NDIL manufactures and supplies curriculum-ready STEM kits for schools and educational institutions:

*   **Lotus Effect Superhydrophobicity Kit** (INR 8,000): Surface science, fluid dynamics, and materials engineering.
*   **Fibonacci Packing Optimization Kit** (INR 12,500): Spatial efficiency algorithms, packaging layout design, and structural optimization.
*   **Termite Mound Thermodynamics Kit** (INR 10,500): Passive ventilation, thermal control, and fluid mechanics simulation.
*   **Swarm Robotics Nesting Kit** (INR 15,000): Decentralized coordination, path planning, and collaborative robotics.
*   **Leaf Vein Fluid Network Kit** (INR 9,500): Biological hydraulics, transport networks, and supply-chain systems routing.

## 🤝 Partnerships & Economic Models
The lab's operations are designed to sustain themselves financially while delivering measurable public impact:
- **Industry Integration**: Operational placement pipelines with regional giants like **Larsen & Toubro (L&T)** (cad/assembly internships) and **Gujarat State Fertilizers & Chemicals (GSFC)** (process engineering).
- **Earn-While-Learn Program**: Connects student cohorts with local MSMEs to deliver freelance CAD modeling and rapid prototyping as paid, faculty-monitored internships.
- **Capital Subsidy Support**: Aligned under the Center for Entrepreneurship Development (CED), Government of Gujarat, securing a 50% CapEx subsidy.
- **CSR Alignment**: Structured to leverage corporate CSR funds (under India's 2% CSR mandate) to sponsor the operational costs of the *BioLab-on-Wheels* in underserved rural areas.

## 🛠️ Technology & Design Stack

This web showcase is constructed using lightweight, high-performance vanilla web standards:
- **HTML5**: Structured semantic markup optimized for search engines (SEO) and accessibility.
- **CSS3 (Vanilla)**: 
  - Sleek, modern dark-mode aesthetic with custom green/slate design tokens (`--accent: #6ecb57`).
  - Fluid responsive layouts using flexbox, CSS Grid, and custom variables.
  - Radial gradient backgrounds and interactive micro-transitions on hover.
- **JavaScript (ES6)**: 
  - High-performance `IntersectionObserver` to track page position and dynamically activate navigation highlights.
  - Smooth scroll behavior for target sections.

## 🚀 Getting Started

To run the application locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Devvv07/Nature-Derived-Innovation-Lab.git
   cd Nature-Derived-Innovation-Lab
   ```

2. **Run a local development server:**
   You can open `index.html` directly in your browser or run a simple local server. For example, using Python:
   ```bash
   python -m http.server 8000
   ```
   Then open your browser and navigate to `http://localhost:8000`.
